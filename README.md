# Computational statics exercises

These are selected statics assignments where I used Python or MATLAB to support the hand calculations. The scripts helped with repeated calculations, numerical integration, plotting, and checking equilibrium-based results.

The folders follow the original homework sequence. Examples include reaction-force calculations, bending-moment evaluation, geometric or inertia calculations, and plots used in the submitted solutions.

## Running

Python files generally require NumPy and Matplotlib. MATLAB files can be opened directly in MATLAB. Small generated plots and text outputs are included when they make a calculation easier to inspect. Submitted reports, handwritten solution photographs, student identifiers, and chat screenshots are omitted.

## Scope

This is a course archive, not a structural-design tool. The scripts solve the specific textbook or assignment cases represented in each folder and should not be used for engineering decisions without independent verification.
